# Troubleshooting - Real Problems and Solutions

## Problem 1: Container in bootloop (password error)

**Symptom:** The container restarts infinitely. The logs (`docker logs wireguard`) show errors related to the password hash.

**Cause:** Version 14+ of wg-easy changed the password format: it no longer accepts plaintext in the `PASSWORD` variable, but requires a pre-generated Bcrypt hash in the `PASSWORD_HASH` variable.

**Solution:** I pinned the version to **13** in the Docker Compose (`image: ghcr.io/wg-easy/wg-easy:13`), which still accepts plaintext passwords. If you want to use v14+, you need to:

```bash
# Generate the Bcrypt hash
docker run -it ghcr.io/wg-easy/wg-easy wgpw 'LaMiaPasswordSegretà

# Use the result in the compose:
# - PASSWORD_HASH=$$2a$$12$$xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
# Note: $ signs must be doubled ($$) in the YAML file to avoid escaping
```

## Problem 2: Connected but no Internet ("The Limbo")

**Symptom:** The phone connects to the VPN (handshake completed, traffic visible), but no web page loads.

**Cause:** I had set `WG_DEFAULT_DNS=192.168.0.250` thinking I would use the future Pi-hole. But Pi-hole was not yet installed. The VPN client was sending DNS queries to a nonexistent server.

**Solution:** Changed to `WG_DEFAULT_DNS=8.8.8.8` (Google DNS) and, **critical step**, I deleted and recreated the client from the Web UI. DNS settings are "baked" into the client configuration file at creation time. Modifying the server-side does not update already-generated clients.

## Problem 3: Instability on 4G mobile networks

**Symptom:** On home Wi-Fi, the VPN works perfectly. On 4G mobile network, the connection is slow or drops after a few seconds.

**Cause:** Packet fragmentation. WireGuard's default MTU (~1420) added to the mobile carrier's overhead (which further encapsulates the traffic) exceeded the physical MTU of the link, causing fragmentation and retransmissions.

**Solution:** Added `WG_MTU=1280` in the Docker Compose. 1280 bytes is the most conservative value that guarantees compatibility with any network, including mobile networks with GTP tunneling.

## Daily usage

1. Open the browser and go to `http://<IP_RASPBERRY>:51821`
2. Enter the password
3. Click **+ New Client** and give it a name (e.g., "iPhone", "Work-Laptop")
4. Download the **WireGuard** app on the device (iOS, Android, Windows, macOS, Linux)
5. Scan the **QR Code** generated by the Web UI (or download the `.conf` file)
6. Activate the VPN when you are away from home

### Verification test

To confirm the VPN is working:

1. Connect the phone to the **cellular hotspot** (simulates an external network)
2. Activate the VPN
3. Try reaching the Portainer Web UI (`https://192.168.0.102:9443`)
4. If it loads, the VPN works and you have access to the home LAN
